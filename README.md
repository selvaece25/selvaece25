- 🧠 **Multi-agent workflows**: worker agents write code test-first, and a fresh verifier agent checks each result before a pull request
- 🌳 **Parallel work** in separate git worktrees, one task per pull request
- 🛠️ **Custom skills, hooks and slash commands** that make Claude Code fit my team's flow
- 🔌 **MCP servers** that connect agents to tools like Jira and GitHub
- 📊 **Usage dashboards** that track tokens, cost and agent results
